# Game-ready asset library

- `models/`: buildings, crops, animals, characters, vegetation, props, roads, bridges, fences, environment
- `textures/`: terrain, buildings, vegetation, water, effects
- `ui/`: icons, panels, buttons, frames, badges, backgrounds
- `fonts/`: Unicode font families for Khmer, Latin and Chinese
- `shaders/`, `particles/`, `animations/`: imported production resources
- `audio/`: music, ambience, UI, animal and gameplay audio

Reference artwork belongs in `res://references/`, never in the runtime asset library.
