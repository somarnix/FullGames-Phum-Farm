# Phum Farm Study Book

## Beginner

Learn Unity scenes, GameObjects, components, prefabs, C# classes, fields, methods, lists, input, colliders, UI anchors, and ScriptableObjects. Exercise: create one plot that moves from empty to tilled.

## Intermediate

Learn state machines, event-driven UI, timestamps, serialization, atomic transactions, object pooling, data validation, test fixtures, and Git branches. Exercise: save a planted crop, reload it, and finish growth.

## Advanced

Learn content catalogs, migration, dependency direction, profiling, mobile rendering, addressable assets, localization, accessibility, failure injection, and deterministic tests. Exercise: corrupt the main save and recover the backup without losing the last valid farm.

## Professional

Learn release management, telemetry, privacy, server authority, cloud conflict resolution, fraud prevention, live economy operations, incident response, customer support, and content pipelines. Exercise: design a secure trade that cannot duplicate or lose an item.

## Review questions

What object owns the state? Can the action fail halfway? What happens when storage is full? Does reload reproduce the same result? Can an old save migrate? Does the UI explain a block? Can new content be added without copying system code?
