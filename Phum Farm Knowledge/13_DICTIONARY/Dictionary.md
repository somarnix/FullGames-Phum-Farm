# Dictionary

| Term | Meaning in Phum Farm |
|---|---|
| Definition | Data describing one crop, item, animal, recipe, building, or expansion |
| Instance | A placed or active copy of a definition in the player's farm |
| Game state | The current facts that must be saved |
| Vertical slice | One complete playable path through UI, rules, state, art, and tests |
| Atomic transaction | An operation that either completes fully or changes nothing |
| Migration | Code that upgrades an older save structure safely |
| Catalog | The validated collection of all content definitions |
| Gate | A build milestone with clear proof before later work begins |
| Offline progress | Timer progress calculated from saved and current time |
| Server authority | The server decides valuable online transactions and rejects cheating |
| Live operations | Ongoing events, content, balance, support, and monitoring after release |
| Placeholder art | Temporary visuals used while gameplay is being built |
