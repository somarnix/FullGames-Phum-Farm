# Documentation QA Checklist

Use this checklist when the plan changes.

- The README links to every major section.
- The simple game scope stays smaller than the growth roadmap.
- Planned work is not described as implemented.
- Current status cites only source or test evidence actually present.
- Each build gate has an observable playable checkpoint.
- Feature names match Unity source and content ids.
- Save changes include migration requirements.
- New screens include failure, empty, loading, and disabled states.
- New content includes id, localization, balance, visuals, and tests.
- Roadmap stages describe dependency order without promising dates.
- Links resolve and no section depends on an old engine or Word document.
