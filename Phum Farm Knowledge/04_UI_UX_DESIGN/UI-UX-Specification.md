# UI and UX Specification

## Required screens

Main menu, loading, farm HUD, contextual action panel, seed selection, barn, shop, build mode, production queue, animal panel, order board, farm journey, daily goals, achievements, map, profile, settings, help, pause, level-up, and reward popup.

## HUD

Show level, XP progress, coins, gems, selected crop, current objective, day/time, and primary navigation. Keep the center clear for the farm. On mobile, place common actions within thumb reach.

## Controls

Desktop uses WASD or click movement, mouse wheel zoom, drag pan, Q/R rotation, E or Space interaction, and Escape pause. Mobile uses tap, drag, pinch, contextual action buttons, and safe-area-aware layout.

## Feedback rules

Every action must show success, blocked reason, cost, reward, or progress. Disabled buttons explain what is missing. Spending gems asks for confirmation. Saving shows a short non-blocking message.

## Accessibility

Do not communicate state with color alone. Use readable contrast, scalable text, large touch targets, reduced motion option, independent music/effects volume, vibration toggle, and subtitles for spoken dialogue.

## UI acceptance

Test at 16:9, 16:10, ultrawide, and common phone ratios. No clipped text, overlapping panels, unreachable controls, or missing localization keys are accepted.
