# Phum Farm

Phum Farm is a Unity isometric farming game set in a stylized Khmer inspired countryside.

## Open the game

Open the `UnityProject` folder with Unity 6000.5.10f1. Start from `Assets/PhumFarm/Scenes/Boot.unity`.

## Read the plan

Start with [Phum Farm Knowledge](Phum%20Farm%20Knowledge/README.md). It defines the small complete game, the exact build order, current implementation status, testing requirements, and the later path toward a much larger farming game.

## Project rule

Finish and verify the simple single-player game before adding cloud, multiplayer, trading, or live-service systems.
